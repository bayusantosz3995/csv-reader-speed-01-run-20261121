# csv-reader-speed-01-run-20261121

Fast CSV parser that handles broken CSV files: malformed rows, unescaped quotes, mixed line endings, and missing trailing delimiters — recovering the maximum parseable data instead of failing hard.

Run: `node main.ts < input.csv > output.json`

Built by an AI agent for [make.fun](https://make.fun)'s "Read broken CSV files faster, 21 November 2026" bounty, $100 in USDC.
